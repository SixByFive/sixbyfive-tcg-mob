## What

Hardcoded `ASSET_BASE_URL` fallback strings in three files reference `backendtcg.sixbyfive.com` (the old WordPress backend, still live):

- `app/(tabs)/messages.js`
- `app/messages/[userId].js`
- `components/profile/ProfileTopCard.js`

The `app.json` prod URL fields contain `REPLACE_WITH_PROD_API_URL` as a placeholder.

## Why

The new tcg-runtime backend does not yet have a production domain. `backendtcg.sixbyfive.com` is the safe fallback â€” it's the old backend, still live, still serving assets.

## When to resolve

When the new backend is deployed to a production URL:
1. Replace `REPLACE_WITH_PROD_API_URL` in `app.json` with the real domain
2. Update the three JS fallback strings from `backendtcg.sixbyfive.com` to the new domain
3. Set `EXPO_PUBLIC_DEV_MODE: false` before building
