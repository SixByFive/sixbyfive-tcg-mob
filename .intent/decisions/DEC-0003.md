## Context

The old `@sixbyfive/tcg-binder` package exported React hooks like `useMeQuery`, `useSearchUsersLazyQuery`, and `useUserProfileQuery` that were used throughout many components. Replacing every import site with raw `useQuery(MeDocument, ...)` calls would require changes to 15+ files.

## Decision

Create thin hook shim files in `hooks/` that wrap `useQuery`/`useLazyQuery` with the correct local document and export the same name:

- `hooks/useMeQuery.js` â€” wraps `useQuery(MeDocument, options)`
- `hooks/useSearchUsersLazyQuery.js` â€” wraps `useLazyQuery(SearchUsersDocument, options)`
- `hooks/useUserProfileQuery.js` â€” wraps `useQuery(UserProfileDocument, options)`

Components import from these local hook files. The import path changes from `@sixbyfive/tcg-binder` to a relative `../../hooks/useMeQuery`, but the hook signature is identical.

## Consequences

- Minimal diff per file â€” only the import path changes.
- Shim files are the injection point if we ever add default options, error tracking, or caching policy overrides.
- Any new generated hooks needed in future should follow this same shim pattern.
