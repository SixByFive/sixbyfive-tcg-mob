## Context

The old WordPress backend and the new tcg-runtime gateway have different field naming conventions for card and collection-related types. All GQL documents needed updating to match the new schema.

## Decision

All local GQL documents use the new field names. The mappings are:

| Old (WordPress) | New (tcg-runtime) |
|-----------------|-------------------|
| `card(id:)` | `cardsearchCard(id:)` |
| `searchCardsConnection(...)` | `searchCards(input: CardSearchInput!)` |
| `image` | `images { small large }` |
| `set` or `setName` | `setCode` |
| `prices` or `pricing` | `latestPrices` |
| `searchUsers(query:)` | `searchUsers(q:)` |
| `unreadCount` | `unreadMessageCount` |
| `registerExpoPushToken â†’ { ok, error }` | `registerExpoPushToken â†’ Boolean!` |

`searchCards` returns `{ total: Int!, items: [CatalogCard!]! }` (flat, not a connection/edges structure).

- Any future query against card fields must use new names.
